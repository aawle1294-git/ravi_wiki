# 서버 접속 및 기본 룰

마인크래프트 레전드 RPG **라비서버(RAVI SERVER)**에 오신 것을 환영합니다!  
원활한 모험을 위해 접속 방법과 기본 규칙을 꼭 확인해 주세요.

---

## 1. 서버 접속 방법

1. **마인크래프트 실행**: 마인크래프트 자바 에디션(Java Edition)을 실행합니다. (권장 버전: 1.21.x 계열)
2. **멀티플레이 메뉴 진입**: 메인 화면에서 `멀티플레이(Multiplayer)`를 클릭합니다.
3. **서버 추가**:
   - 서버 이름: `라비 서버`
   - 서버 주소: `mcravi.m-c.kr`
   - 서버 리소스팩: **'사용(Enabled)'**으로 설정 권장 (커스텀 아이템 외형 및 UI 표시용)
4. **접속 완료**: 서버 목록에서 추가된 라비 서버를 더블 클릭하여 접속합니다.

::: tip 💡 리소스팩 안내
라비서버는 전용 무기, 화려한 이펙트, 커스텀 GUI를 지원하므로 **서버 리소스팩을 반드시 다운로드 및 적용**해 주셔야 정상적인 플레이가 가능합니다. 리소스팩 다운로드가 안 될 경우 서버 목록에서 서버 편집 → 리소스 팩 '사용'으로 변경해 주세요.
:::

---

## 2. 서버 기본 규칙

라비서버는 쾌적하고 공정한 게임 환경 조성을 위해 다음과 같은 행위를 엄격히 금지합니다.

- **비인가 프로그램 사용 금지**: X-Ray, 핵, 오토마우스(매크로), 치트 클라이언트 사용 적발 시 영구 차단.
- **버그 악용 금지**: 게임 내 버그나 복사 취약점 발견 시 악용하지 않고 디스코드 `#버그제보` 채널로 즉시 제보해야 합니다. (악용 시 회수 및 제재)
- **욕설, 비방 및 유저 간 분쟁 유발 금지**: 전체 채팅에서의 비속어, 특정 유저 저격, 도배 행위는 채팅 금지 또는 제재 대상입니다.
- **현금 거래(RMT) 금지**: 운영진의 승인 없는 인게임 재화/아이템의 현금 및 외부 재화 거래는 전면 금지됩니다.

## 3. 초보자 정착 가이드 (초반 루틴)

1. **튜토리얼 완료**: 스폰 지역에서 안내 NPC와 대화하고 기본 가이드 퀘스트를 완료합니다.
2. **초보자 지원 상자 수령**: `/메뉴` 또는 스폰 NPC를 통해 초보자용 기본 무기와 방어구 세트를 지급받습니다.
3. **직업 선택**: 직업 전직관 NPC를 찾아가 본인의 플레이 스타일에 맞는 기본 직업(전사, 마법사, 궁수 등)을 선택합니다.
4. **1구역 사냥터 이동**: `/메뉴`의 워프 기능을 이용해 초보자 사냥터(1구역 슬라임/고블린 서식지)로 이동하여 레벨을 올립니다.
5. **디스코드 연동**: 공식 디스코드(`https://discord.com/invite/qeZCRqqbhs`)에 접속하여 계정을 연동하면 연동 특별 보상을 획득할 수 있습니다.
